# Interview prep notes

Plain Markdown notes for senior backend interviews. One concept per file. Write each note from memory after studying, then revise it on the schedule in [revision-log.md](revision-log.md).

| Folder | What goes in it |
| --- | --- |
| `00-cheatsheets/` | One page per area, written at each consolidation week |
| `01-java/` | Core Java |
| `02-spring/` | Spring Boot (e.g. `beans-and-di.md`, `transactional.md`) |
| `03-databases/` | SQL, JPA, indexing, transactions |
| `04-distributed/` | Kafka, Redis, microservices, cloud |
| `05-dsa/` | [problem-log.md](05-dsa/problem-log.md) (one line per problem), `problems/` (full notes per problem), `patterns/`, the [edge-case checklist](05-dsa/edge-case-checklist.md) |
| `06-lld/` | Low-level design |
| `07-system-design/` | One note per design |
| `08-ai-engineering/` | LLMs, agents, RAG, evals, MCP, Python for Java devs |
| `09-behavioral/` | Story bank (STAR) |
| [10-mistakes.md](10-mistakes.md) | Every wrong answer, with the right one in my words |
| [revision-log.md](revision-log.md) | Spaced revision dates for every note |

**Concept note template:** `# Title` · `Last revised · Confidence` · 60-second explanation · How it works underneath · Code example (from my own project) · Gotchas · Interview questions · Links.
